# Problem Definition
## Introduction
We decided to create a film recommendation web application, with a name still to be defined (as of 1st June).

## Problem Statement
We thought it would be relevant given the growing number of movies that are released each year, in order to help users discover new films that might match their personal taste using a system that accounts for their preferences.


The goal of our system is building a webapp that gives personalized recommendations based on a set (something along the lines of 5 or 10 films) given by the user themselves.


Our solution uses machine learning models trained on a preexisting Netflix film dataset. This model will be deployed within a web interface built with Streamlit, allowing users to receive immediate feedback from the webapp.


- Users give a relatevely small input
- The output has to be understandable and relevant
