\section{Introduction}

\subsection{Purpose}
The purpose of this document is to define the software requirements for MovieMatch, a web-based movie recommendation system. It allows users to select a set of 5–10 movies they enjoy and then receive personalized recommendations. The system helps users discover new films based on their personal taste using a machine learning model trained on the MovieLens dataset.

\subsection{Scope}
The scope of MovieMatch includes:
\begin{itemize}
    \item User input of 5–10 favorite movies
    \item Backend recommendation generation using an ML model
    \item Web interface for input and results visualization
    \item Display of relevant movie information (title, genre, rating)
    \item Deployment on Streamlit Cloud
\end{itemize}

\subsection{Definitions, Acronyms and Abbreviations}
\begin{itemize}
    \item ML – Machine Learning
    \item UI – User Interface
    \item API – Application Programming Interface
    \item MovieLens – Dataset used for model training
\end{itemize}

\section{Overall Description}

\subsection{Product Perspective}
MovieMatch is a standalone, Streamlit-based web application that provides personalized movie recommendations. It uses a content-based or collaborative filtering ML model and is trained on user-movie interactions.

\subsection{Product Functions}
\begin{itemize}
    \item User selects 5–10 movies from a dropdown list
    \item System returns 10 recommended titles using an ML model
    \item Recommendations include title, genre, rating, and poster
    \item Web UI built in Streamlit
\end{itemize}

\subsection{User Characteristics}
\begin{itemize}
    \item Casual users who want simple movie recommendations
    \item Developers and evaluators reviewing the project
\end{itemize}

\subsection{Constraints}
\begin{itemize}
    \item Model must load in less than 5 seconds
    \item Dataset limited to 100MB (due to hosting)
    \item App must run on Streamlit Cloud
\end{itemize}

\subsection{Assumptions and Dependencies}
\begin{itemize}
    \item Users have internet access
    \item Dataset is pre-cleaned and available locally
    \item External dependencies are installable via \texttt{requirements.txt}
\end{itemize}

\section{Specific Requirements}

\subsection{Functional Requirements}
\begin{itemize}
    \item FR1: Allow user to select 5–10 favorite movies
    \item FR2: Return top 10 movie recommendations
    \item FR3: Display each result with title, genre, rating, poster
    \item FR4: Validate input and handle edge cases (e.g., <5 movies selected)
\end{itemize}

\subsection{Performance Requirements}
\begin{itemize}
    \item Recommendation generation must take < 2 seconds
    \item App must handle 10+ concurrent users
    \item Model must load in < 5 seconds
\end{itemize}

\subsection{Interface Requirements}
\begin{itemize}
    \item Simple UI using Streamlit components
    \item Multiselect for movie input
    \item Result section with images and descriptions
\end{itemize}

\subsection{Operational Requirements}
\begin{itemize}
    \item App must be deployable on Streamlit Cloud
    \item Codebase must be modular (\texttt{app.py}, \texttt{model.py}, etc.)
\end{itemize}

\subsection{Security Requirements}
\begin{itemize}
    \item Prevent code injection or unintended execution
    \item No login required; keep interface safe and read-only
\end{itemize}

\subsection{Software Quality Attributes}
\begin{itemize}
    \item Usability: Simple, clear interface for all user levels
    \item Reliability: Should handle bad input gracefully
    \item Maintainability: Code should be readable and organized
    \item Scalability: Easy to change dataset or recommendation algorithm
\end{itemize}
